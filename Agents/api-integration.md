# api-integration

REST/JSON, OAuth, webhooks, CRM (KeyCRM…), платіжні (WayForPay…), доставки (Нова Пошта/Укрпошта/Meest), зовнішні сервіси.

## Обовʼязковий чек перед кодом

- rate limits і поведінка при 429;
- retries з backoff (тільки для ідемпотентних викликів!);
- обробка всіх класів помилок (мережа, 4xx, 5xx, таймаути);
- idempotency: повторний webhook/запит не створює дубль (ключ ідемпотентності або перевірка існування).

## Правила

- Ключі/токени — з config проєкту; у vault — тільки НАЗВА інтеграції і ДЕ лежить конфіг.
- Webhook-ендпоінти: валідація підпису/джерела, швидка відповідь (важке — у чергу/cron).
- Логувати запит/відповідь БЕЗ секретів; тестові виклики — на sandbox, не на прод.
- Готові реалізації шукати в Projects (nadel: KeyCRM+SMS; hydrophob: WayForPay порт з well) перед написанням з нуля.
