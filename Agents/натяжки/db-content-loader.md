# db-content-loader

**Визначення**: `~/.claude/agents/db-content-loader.md` · модель: sonnet

Наповнення каталогу OC3 з CSV/TSV: категорії (+привʼязки, всі мови), структуровані HTML-описи через парсер блоків.

## Коли використовувати
- Первинне наповнення натяжки з експорту prom.ua чи подібного.
- Перезаливка описів після зміни структури.

## Ключові знання патерну
- Match по `oc_product.model` = зовнішній id.
- Категорії: category + description(мови) + to_store + **category_path** (без нього стокові запити мовчки порожні).
- Парсер описів: двокрапка→список; `N.` нумеровані групувати попри крапки; короткий рядок без пунктуації→`<h3>`; скіп першого рядка-дубля назви ЛИШЕ при близькій довжині (±10) — інакше зʼїдає нормальні абзаци.
- Класи HTML — з теми (`hp-tabpanel__*`, `hp-post__*`), не голі теги.
- Ідемпотентність: свій DELETE перед INSERT.
- `fgetcsv(..., ',', '"', '\\')` — явні параметри (PHP 8.4 deprecation).

## Промпт-заготовка
```
Наповни категорії+привʼязки з <csv> для локальної БД <назва>@127.0.0.1:8889
(root/root), match по model. Мови 1(uk)+3(ru), ru-назви переклади.
Опиши блоками описи з колонки description_site (fallback description_materials).
Скрипт у scratchpad; для прода згенеруй .sql, не виконуй.
Звіт: linked/missed/порожні описи.
```

## Після агента
Контрольні SELECT-и очима, спот-чек 2-3 товарів на фронті, SQL → підтвердження → прод.
