# backend-php

PHP, MySQL, API, інтеграції, бізнес-логіка, cron, черги, обробка даних.

- Патерни стеку проєкту: OC3 → [[opencart3]]; Laravel → artisan/Eloquent/queues конвенції repo; чистий PHP → стиль існуючого коду.
- Ідемпотентність усього, що запускається повторно (cron, імпорти): свій DELETE/upsert, лок від подвійного запуску.
- Помилки: лог + graceful degradation, не мовчазний die.
- `php -l` кожного зміненого файлу — мінімум; тести проєкту, якщо є.
- Секрети — з config-файлів проєкту, ніколи не хардкодити і не записувати у vault.
