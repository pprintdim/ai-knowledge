# frontend

HTML/CSS/SCSS/JS/jQuery, Twig/Blade, responsive, accessibility, pixel-perfect.

- Еталон верстки — джерело істини (макет/гілка main/живий сайт): 1:1, без самодіяльного дизайну.
- Backend не чіпати без причини; потрібні дані — сказати оркестратору, не лізти в модель самому.
- Клас-конвенції проєкту (hp-*, shk-* тощо) — з `Projects/<repo>/`, не голий bootstrap.
- Закоментований Twig `{# #}` — не чіпати. Блок-HTML не обгортати в `<p>`.
- Перевірка: desktop+mobile рендер, реальні URL (curl/скріншот), не тільки «код виглядає правильно».
- Розбіжності з еталоном системно шукає [[page-auditor]] (read-only).
