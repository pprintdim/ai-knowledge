## 2. Пошукові теми / ключові слова (search themes)
Згруповано по групах оголошень:

**Сайти під ключ**
- створити сайт, розробка сайту, замовити сайт, сайт під ключ, розробка сайту ціна, зробити сайт для бізнесу

**Інтернет-магазини**
- створити інтернет-магазин, розробка інтернет-магазину, магазин на opencart, інтернет-магазин woocommerce, розробка eCommerce

**CMS / платформи**
- сайт на wordpress, розробка wordpress, сайт на opencart, opencart розробник, shopify розробка

**Лендінги**
- замовити лендінг, розробка лендінгу, односторінковий сайт, landing page під ключ

**SEO**
- seo оптимізація сайту, просування сайту, технічне seo, аудит сайту

**Веб-дизайн**
- веб-дизайн сайту, ui ux дизайн, редизайн сайту, дизайн інтернет-магазину

**Бренд / гео**
- веб студія, фрілансер веб розробник, розробка сайтів україна

> Тип відповідності: старт із *фразовою* + *широкою з модифікаторами*; мінус-слова: безкоштовно, скачати, курси, вакансія, шаблон, конструктор, тильда, своїми руками.
