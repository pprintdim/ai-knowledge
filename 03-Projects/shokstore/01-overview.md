# shokstore.com.ua — загальний аналіз сайту

*Дата аудиту: 11.07.2026. Просканованих сторінок: 143 (усі доступні: головна, 6 сторінок каталогу, 16 інформаційних, 120 карток товарів).*

## Що це за сайт

Інтернет-магазин електрошокерів (засоби самозахисту) з доставкою по Україні, орієнтований на Київ. Мова сайту — лише російська. Валюта — грн. Асортимент: 120 товарів у двох класах — **Standart** (дешевші) та **Platinum** (потужніші), майже кожна модель існує у двох версіях (пари типу `/storm` і `/storm_platinum`). Основний виробник — китайська компанія Wei Shi (ТМ «ОСА»). Є розділ оптових продажів і ремонту шокерів.

## Технічний стек

| Компонент | Значення |
|---|---|
| CMS | OpenCart (стара гілка 1.5.x, судячи з роутів і розмітки) |
| Тема | `catalog/view/theme/default` (стандартна) |
| PHP | **5.6.40** (EOL з січня 2019 — без оновлень безпеки 7+ років) |
| Веб-сервер | nginx 1.24.0 |
| HTTPS | **відсутній** — сайт працює тільки по HTTP, порт 443 не відповідає |
| Мобільна версія | **відсутня** — немає `<meta name="viewport">`, тема неадаптивна |
| Аналітика | Google Analytics `UA-39087905-1` (Universal Analytics, **мертвий з липня 2023** — дані не збираються), Яндекс.Метрика (сервіс заблокований в Україні) |
| Соцмережі | VK, Facebook, Twitter, YouTube — через редірект `/go.php?…` (VK заблокований в Україні; лінки застарілі) |

## Структура URL (ЧПУ)

- Головна: `/`
- Каталог: `/shop/`, категорії `/shop/standart/`, `/shop/platinum/`, `/shop/all/`, `/shop/opt/`, `/shop/repair/`
- Інфо-статті: `/info/<slug>/` (11 статей) + `/contact/`, `/rating/`
- Товари: `/<slug>` у корені (наприклад `/storm`, `/osa-928_platinum`)
- Технічні дублі `index.php?route=…` редіректяться на ЧПУ (302, краще 301)
- `www` → без `www`: 301 ✅; неіснуючі сторінки → коректний 404 ✅
- Повне дерево — у [02-structure.md](02-structure.md)

## SEO: сильні сторони

1. **Унікальні тексти на всіх сторінках**: кожен із 120 товарів має опис ~2000–3000 символів, категорії — 1700–3400, інфо-статті — повноцінні статті. Жодної сторінки з текстом < 300 символів.
2. **Title та meta description заповнені всюди** (крім 3 службових сторінок), keywords — на всіх товарах.
3. **Canonical на всіх 120 картках товарів** — дублі шляхів типу `?path=70&product_id=…` закриті.
4. ЧПУ, хлібні крихти, коректні H1 на всіх сторінках.
5. Перелінковка: інфо-статті ↔ категорії ↔ товари, блок «Рейтинг шокерів».

## SEO: проблеми (за пріоритетом)

### Критичні
1. **Немає HTTPS.** Chrome позначає сайт «Не захищено», для Google це фактор ранжування, для покупців — бар'єр довіри при оформленні замовлення.
2. **Немає мобільної версії** (без viewport, неадаптивна тема). Google індексує mobile-first — це б'є по всіх позиціях.
3. **Немає української версії.** Закон про держмову вимагає укр. версію за замовчуванням для e-commerce; також втрачається весь укр. пошуковий трафік. Мова тільки RU, hreflang відсутній.
4. **PHP 5.6** — діри в безпеці, старий OpenCart 1.5 — те саме.

### Важливі
5. **51 пара товарів Standart/Platinum має однакові meta description** (102 сторінки, наприклад `/first_step` і `/first_step_platinum`) — Google бачить масові дублі.
6. **3 дублі title**: `/osa-800` ↔ `/osa-800_platinum`, `/scorpion_1102` ↔ `/scorpion_1102_platinum`, `/storm` ↔ `/storm_platinum`.
7. **86 сторінок з description довшим за ~170 символів** — обрізаються у сніпеті (описи скопійовані з тексту сторінки, а не написані як сніпети).
8. **`sitemap.xml` порожній** (редірект на вимкнений фід `route=feed/google_sitemap`), у `robots.txt` немає директиви `Sitemap:`.
9. **Canonical відсутній на головній, всіх категоріях та інфо-сторінках** (23 сторінки).
10. **Немає мікророзмітки** — ні schema.org (Product, Offer, BreadcrumbList, Organization), ні Open Graph, ні Twitter Cards. Нуль розширених сніпетів.

### Дрібніші
11. Два H1 на головній («Купить электрошокер, шокер в Киеве» + «Добро пожаловать…»).
12. 3 сторінки без description (`information_id=8,10,11` — «Частые вопросы», «Советы покупателям», «Законы»; вони ж без ЧПУ).
13. Мертва аналітика: UA-код не збирає дані з 2023, Метрика заблокована — власник фактично «сліпий», потрібен GA4.
14. Редірект дублів `index.php?route=common/home` → `/` віддає 302 замість 301.
15. `robots.txt` містить застарілу секцію `User-agent: Yandex`, лінки на VK — токсичні сигнали для UA-аудиторії.

## Контент і меню

- **Головна**: H1 «Купить электрошокер, шокер в Киеве», привітальний SEO-текст (~2,4 тис. знаків), блоки «Хиты продаж», «Последние поступления».
- **Категорії** (тексти повністю в [03-seo-pages.md](03-seo-pages.md)): Standart, Platinum, «Весь ассортимент», Опт, Ремонт.
- **Інфо-розділ** — 16 сторінок: про магазин, про Wei Shi, класифікація шокерів, як вибрати, інструкція, підробки, виробники, переваги, доставка, контакти, рейтинг, FAQ, поради, закони.
- **Товари** — 120 карток: title = назва моделі (без комерційних додатків «купить», «Киев», ціни — недовикористаний потенціал), опис 2–3 тис. знаків, ціна, кнопки «В закладки»/«В сравнение». Повний список — у [04-products.md](04-products.md).
