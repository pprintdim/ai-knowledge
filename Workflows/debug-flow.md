# /debug — діагностика без обіцянки фіксу

debug → спеціаліст → ([[database]]) → qa

1. [[debug]]: факти (логи/трейси/git log), гіпотези ранжовано.
2. Спеціаліст підтверджує root cause мінімальним експериментом; SQL-діагностика read-only — [[database]].
3. Вихід: причина + план фіксу (сам фікс — окремо, /fix), у `Projects/<repo>/MEMORY.md` якщо цінне.
