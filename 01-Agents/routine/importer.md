# importer

CSV/XML/XLSX/Google Sheets/supplier feeds: SKU mapping, ціни, залишки, категорії, зображення, інкрементальні оновлення, cron.

## Перед новою реалізацією

ШУКАТИ reusable патерни: `02-Knowledge/OpenCart3/` (imports скоро; зараз — [[database]], [[db-content-loader]]) і `03-Projects/<repo>/` (well має up_search_*, rozetka_delivery_cron; свій движок імпорту може вже існувати).

## Правила

- Match по стабільному ключу (OC3: `oc_product.model` = зовнішній id/SKU).
- Ідемпотентність: повторний запуск = той самий результат (upsert/guarded DELETE).
- Інкрементальність: писати результат порціями на диск (обрив ≠ втрата всього).
- Валідація вхідних даних до запису: кількість колонок, кодування, порожні обовʼязкові поля → звіт (linked/missed/skipped).
- Великі файли — стрімінгом (fgetcsv/XMLReader), не грузити в память цілком.
- Cron-версія: лок-файл, лог короткий, помилки — окремо.
- SQL на прод — генерувати файл, виконання через підтвердження.
