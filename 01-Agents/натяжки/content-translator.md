# content-translator

**Визначення**: `~/.claude/agents/content-translator.md` · модель: sonnet

Масовий переклад uk→ru: мовні PHP-файли каталогу або SQL контенту БД (описи товарів, інфо-сторінки).

## Коли використовувати
- Друга мова сайту: 100+ мовних файлів або десятки описів товарів.

## Головний урок (чому цей агент такий)
Двічі втрачали багатогодинний прогрес: агент падав по session limit / обриву зʼєднання, а результат жив лише в його розмові. Тому **перше правило агента — інкрементальний запис на диск кожні 10–15 одиниць** і вміння продовжити з місця обриву (перевіряє існуючий вихідний файл).

## Промпт-заготовка
```
Переклади на російську вміст <джерело: тека/TSV>.
Вихід: <шлях>.sql (REPLACE INTO ... SELECT, language_id=3, SET NAMES utf8mb4).
ПИШИ ІНКРЕМЕНТАЛЬНО: append кожні 10 товарів.
Якщо файл уже існує — визнач зроблене і продовж, не переробляй.
HTML-класи зберігати 1:1, бренди/терміни не перекладати.
Кількість колонок INSERT vs SELECT звіряй.
```

## Після агента
- Звірити кілька випадкових одиниць очима.
- `grep -c "REPLACE INTO"` = очікуваній кількості; колонки звірити (був факап: інфо-рядки мали на колонку менше — весь файл падав).
- SQL → підтвердження → локально → прод.

## Резюм при падінні
`SendMessage` тому самому агенту: "продовжуй з batch N, не переробляй перші X" — транскрипт зберігається.
