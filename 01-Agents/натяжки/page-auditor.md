# page-auditor

**Визначення**: `~/.claude/agents/page-auditor.md` · модель: sonnet · **read-only** (нічого не редагує)

Аудит 1:1 відповідності сторінок еталонній верстці (гілка main / живий сайт-еталон). Повертає таблицю розбіжностей з критичністю.

## Коли використовувати
- Перед здачею сторінки; коли користувач каже «не відповідає верстці»; регулярний прохід по всіх сторінках.

## Маркери «не той стан», які він шукає
- Стоковий bootstrap (panel/accordion/alert/ul.pagination) замість hp-класів.
- `index.php?route=` лінки там, де вже є слаги.
- Грід замість слайдера (де в еталоні swiper).
- Відсутні/переставлені секції, не ті SVG-іконки, хардкоджені тексти замість мовних ключів.

## Промпт-заготовка
```
Порівняй сторінку <url локальний/прод> з еталоном git show main:<файли секцій>.
Пройди секції зверху вниз. Таблиця: Секція | Еталон | Фактично | Критичність.
Нічого не редагуй. Запропонуй порядок виправлень.
```

## Після агента
Оркестратор сам виправляє за пріоритетом (або скидає механічне на [[layout-porter]]).
